## 🚀 About This Repository

> **HackerRank's 30 Days of Code** is a month-long challenge designed to help developers strengthen their programming foundations — covering data types, data structures, algorithms, and object-oriented design.

This repository contains my **clean, well-commented solutions** to every problem in the challenge. Each solution is written with clarity and best practices in mind — not just to pass the tests, but to be understood.
